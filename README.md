# 投稿アシスタント 使い方

どのお店でも使える、Instagram投稿の画像と文章を作る道具です。
Museを入れていないスマホでも使えます（HTMLファイルを開くだけ）。

## 手順
1. ファイル（index.html）をスマホで開く
2. 最初に1回だけ「お店の設定」に店名を入れる（投稿文のハッシュタグになります）
3. 写真を選ぶ → 種類をタップ → タイトルと一言メモを書く
4. 見た目を整える：ライン（手書き風のかすれ・2重もあり）、色、フォント、文字の位置・大きさ・白いフチ
5. 「画像を保存する」→ スマホに 1080×1350 の画像が保存されます
6. 「投稿文をコピー」→ Instagramアプリを開いて、保存した画像を選んで、文章を貼って投稿（投稿は人の手でします）

## 画像について
- 出来上がりは Instagram の縦長そのまま（1080×1350＝4:5）なので、投稿画面で上下が切れることはありません
- 元の写真を 4:5 に合わせるとき、端が少し切り取られます。プレビューに写っている範囲がそのまま保存されるので、プレビューで確認してください（縦長の写真がおすすめ）

## 任意
- 「Museに整えてもらう文をコピー」を使うと、文章を整える頼み文がコピーできます。お店の Muse／Muse アプリに貼ると整えた案が返ってきます（使わなくても投稿できます）
- 価格・営業時間・商品名は、入力したものだけが文章に入ります。勝手に作りません
